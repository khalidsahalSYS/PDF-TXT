# تحويل TXT إلى PDF

تطبيق ويب بسيط باللغة العربية لتحويل ملفات النصوص (`.txt`) إلى PDF باستخدام HTML وCSS وJavaScript، دون مكتبات خارجية.

## الاستخدام

1. افتح `index.html` في متصفح حديث.
2. اختر ملف `.txt` من جهازك.
3. اضغط **طباعة / حفظ PDF**.
4. في نافذة الطباعة، اختر **Save as PDF / حفظ كملف PDF** ثم احفظ الملف.

> يعتمد إنشاء ملف PDF على ميزة الطباعة المدمجة في المتصفح. لا يتم رفع الملف أو إرساله إلى خادم؛ تتم قراءته محليًا داخل المتصفح.

## التشغيل عبر GitHub Pages

يمكن نشر التطبيق من إعدادات المستودع:

1. افتح **Settings → Pages**.
2. اختر الفرع `main` ومجلد الجذر (`/root`) كمصدر للنشر.
3. احفظ الإعدادات وانتظر اكتمال النشر.

بعدها سيظهر رابط الموقع في صفحة إعدادات GitHub Pages.
